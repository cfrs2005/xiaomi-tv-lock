# Agent Skill：INSTALL

## 目标
在不破坏用户现有电视环境的前提下安装/升级 TV Lock，并确认应用具备所需运行条件。

## 必读
先读 `AGENTS.md`、`docs/HANDOFF.md`、`docs/DEVICE-MFTR0.md`。

## 执行流程
1. 检查本机是否有 adb：`adb version`。
2. 连接用户指定电视，执行 `adb devices`；必须显示 device。
3. 只读识别型号、SDK、固件、CPU ABI、现有包、悬浮窗/通知监听/无障碍授权、Device Owner 状态。
4. 检查 Git 工作区、构建工具、签名密钥是否存在；不得生成新密钥覆盖已有密钥。
5. 构建 APK，保留构建日志和 SHA256。
6. 安装前检查签名兼容性和版本；不要卸载旧包以绕过签名问题。
7. 安装/升级需用户明确授权；不自动 reboot。
8. 检查安装成功、包信息、权限、服务声明。
9. 执行非破坏性 smoke test；待机/重启测试另行征求用户同意。
10. 报告每步真实输出摘要和未完成项。

## Device Owner
安装应用不等于注册 Device Owner。先在当前设备上检查 provisioning 条件；不要退出小米账号、清除数据或恢复出厂。注册失败就停止并报告，不得自动重置设备。

## 通过标准
包已安装、签名/版本正确、必要授权可核验、基础 UI 可启动；不得把“APK 安装成功”描述成“整机锁定成功”。

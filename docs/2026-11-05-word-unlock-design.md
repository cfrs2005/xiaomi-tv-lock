# 背单词解锁 — 产品设计文档

> 日期：2026-11-05 · 状态：待评审 · 技术方案见 [`2026-11-05-word-unlock-tech.md`](2026-11-05-word-unlock-tech.md)

## 1. 要解决什么

现在的锁只有一条路：输 4 位 PIN。由此产生三个实际问题：

1. **孩子不知道密码就只能干等**，家长不在家时电视等于废掉。
2. **知道密码就等于畅通无阻**，没有"看多久"的概念，一坐一下午。
3. 密码是家长设的，对孩子没有任何正向激励——它只是一道禁止线。

改成两条路并行：

| 路径 | 谁用 | 换来什么 |
|---|---|---|
| 输入 PIN | 家长 | 15 分钟观看 |
| 做完一组单词 | 孩子 | 15 分钟观看 |

核心不是"防住孩子"，是**把看电视变成要付学费的事**。所以单词这条路的难度必须真实：默写，不是点选。

## 2. 核心规则

| 规则 | 值 | 备注 |
|---|---|---|
| 单次解锁时长 | 15 分钟 | PIN 与单词共用同一套计时 |
| 每组单词数 | 10 | 学习 1 轮 + 默写 1 轮 |
| 通过线 | 正确率 > 60% | **待确认，见 §7.1** |
| 未通过 | 再来一组 10 个 | 不设轮数上限，靠 PIN 兜底 |
| 同一单词的冷却 | 7 天 | 做过的词 7 天内不再出现 |
| 词库规模 | 高考 3500 | 已落地 3796 条，来自公开词表，见 `assets/NOTICE.md` |

### 2.1 关于「15 分钟」

计时从**解锁成功那一刻**开始，不区分 PIN 还是单词。

- 到点自动重新上锁，不弹窗商量。
- 剩余 1 分钟、10 秒各提示一次（顶部细条，不挡画面）。
- **待机仍然立即上锁**，15 分钟不跨越待机。这是原有需求的硬约束：每次唤醒都要重新解锁。
- 15 分钟内再次进入待机，回来还是要解锁，不续期。

### 2.2 关于「7 天冷却」

「做过的词 7 天内不再出现」按字面实现：只要某词进过某一组，无论答对答错，`last_seen_at` 立刻更新，7 天后才重新进入候选池。

这带来一个副作用需要知情：**同一组里答错的词，当天不会重练**。从记忆规律看，当天错当天复习比隔 7 天有效得多。但这是你明确提的规则，我按规则实现，把"错题当天重练"做成一个默认关闭的开关（`wrong_retry_hours`）。见 §7.2。

### 2.3 关于「考试」

- 10 个词，逐个默写，**答错当场提示**（红字 + 正确答案立刻给不给？见 §7.3）。
- 10 题答完才算一轮结束，中途不能提交。
- 通过 → 显示"解锁 15 分钟"，锁屏消失。
- 不通过 → 显示本轮成绩 + 哪些错了，然后"再来一组"。

## 3. 流程

### 3.1 解锁主流程

```
                    ┌──────────────────────────┐
                    │   锁屏（PIN 键盘页）      │
                    │   ┌──────────────────┐   │
                    │   │  我不知道密码     │   │  ← 新增入口
                    │   └──────────────────┘   │
                    └───────────┬──────────────┘
                                │ 点"我不知道密码"
                                v
                    ┌──────────────────────────┐
                    │   选项页                  │
                    │   · 背单词解锁            │
                    │   · 返回输密码            │
                    └───────────┬──────────────┘
                                v
                    ┌──────────────────────────┐
                    │  学习页：10 个词全列      │
                    │  英文 / 词性 / 中文       │
                    │  [ 开始默写 ]             │
                    └───────────┬──────────────┘
                                v
                    ┌──────────────────────────┐
                    │  默写页（循环 10 次）     │
                    │  中文 + 词性              │
                    │  字母砖块拼写             │
                    │  第 i/10 题               │
                    └───────────┬──────────────┘
                                v
                    ┌──────────────────────────┐
                    │  结果页                   │
                    │  正确率 70%  → 解锁 15 分钟│
                    │  正确率 50%  → 再来一组    │
                    └──────────────────────────┘
```

### 3.2 判分与循环

```
一轮开始：取 10 个到期词 → 学习 → 默写 10 题 → 统计
                                              │
                      ┌───────────────────────┴──────────────┐
                  正确 ≥ 7                               正确 ≤ 6
                      │                                      │
              解锁 15 分钟                     提示"错得有点多，再来一组"
                                                             │
                                                     回到"取 10 个到期词"
```

## 4. 界面

### 4.1 锁屏新增入口

PIN 键盘下方加一行次要按钮：`我不知道密码`。视觉上要弱于键盘——小字、无填充，避免孩子一上来就点它。

点开后是两行：

```
我不记得密码
   ① 背单词解锁        ← 主选项
   ② 返回输密码
```

### 4.2 学习页

一屏列出 10 个词，2 列 × 5 行，每行三栏：

```
well          adv.    很好地；水井
environment   n.     环境
...
```

遥控器只有上下左右，这里**不需要焦点**——纯阅读页，唯一可聚焦的是底部 `开始默写`。看多久不限。

> 页面上要写一句提示：`看完了点下面开始默写，单词会消失`。避免孩子以为能边看边写。

### 4.3 默写页

```
        第 3 / 10 题

        环境                        ← 中文提示（大字号）
        n.                          ← 词性

        _ _ _ _ _ _ _ _ _ _ _       ← 下划线数量 = 字母数

     ┌──┬──┬──┬──┬──┬──┐
     │ e│ n│ v│ i│ r│ o│          字母砖块（答案字母 + 3 个干扰字母，打乱）
     ├──┼──┼──┼──┼──┼──┤
     │ m│ t│ a│ n│ e│ n│
     └──┴──┴──┴──┴──┴──┘
        [ 退格 ]    [ 提交 ]
```

- 字母砖块拼写替代全键盘：26 键 QWERTY 在遥控器上一个 10 字母单词要按 30+ 次，孩子会放弃。
- 砖块 = 该词的全部字母 + 3 个干扰字母，混排。答满位数即可提交。
- 答错：红字提示 + 正确答案停留 1.5 秒，然后进下一题。
- 长按/多次按同一个砖块不应重复选取（取过即置灰）。

### 4.4 结果页

```
        这一组做完啦

        答对 7 / 10        正确率 70%

        ✗ environment  →  environmental   ← 错题回看（最多列 5 条）
        ✗ well         →  good

              [ 解锁 15 分钟 ]
```

未通过时按钮换成 `再来一组`，并说明`错题太多，需要再做一组`。

### 4.5 家长侧维护界面

在设置页（MainActivity，需 PIN 解锁后才能进）：

- 词库统计：总词数 / 已学 / 待复习 / 错题数
- `从 Download 导入词库`（读 `/sdcard/Download/tvlock_words.csv`）
- `重置学习进度`（保留词条，清空 last_seen / 统计）
- `导出错题本`（写 `/sdcard/Download/tvlock_wrong.csv`）

## 5. 词库

### 5.1 规模与来源

3796 条，覆盖高考大纲（目标 3500，略多）。字段：`英文 / 中文 / 词性 / 排序键`。

数据来自公开仓库 [pluto0x0/word3500](https://github.com/pluto0x0/word3500)（MIT），由
`tools/build_wordbank.py` 解析生成 `assets/words_gaokao.csv`。**不是我手写的**——手写几千条释义
必然出错，而错一个释义孩子就记错一个词。来源、转换规则和已知瑕疵都记在 `assets/NOTICE.md`。

词性无法识别的 57 条都是短语（`junk food`、`Christmas tree`），UI 隐藏词性栏。

家长仍可导入自己的词表覆盖式合并，格式：

```csv
en,zh,pos,level
well,很好地；水井,adv.,1
environment,环境,n.,1
```

`level`：1 高频 / 2 常考 / 3 拓展。选词时优先 1。

### 5.2 维护动作

| 动作 | 触发者 | 频率 |
|---|---|---|
| 首次建库（内置 300 条） | 首启自动 | 一次 |
| 批量导入 | 家长，手动 | 按需 |
| 重置进度 | 家长，手动 | 按需 |
| 词条禁用（个别词不想考） | 暂不做 | — |

## 6. 异常与边界

| 情况 | 行为 |
|---|---|
| 到期词不足 10 个 | 有几个考几个，≥5 个才允许开始；不足 5 个提示"词库不够了，先用密码" |
| 词库完全为空 / 数据库损坏 | 隐藏"背单词"入口，只能输 PIN（fail-closed） |
| 孩子在默写中点返回 | 退回锁屏，不解锁，已答题作废 |
| 孩子在默写中待机 | 待机照常上锁；回来从头开始这一组 |
| 连续多组不通过 | 不设上限，但每轮结束都提示可以按返回改用密码 |
| 家长忘记 PIN 且孩子过不了 | 只能 ADB 解除保护（`docs/RECOVERY.md` R2），这是既有设计，不额外开洞 |
| 词库导入失败 | 保留原库不动，报错行号 |

## 7. 已确认的规则（2026-11-05）

### 7.1 通过线：答对 ≥7 才算过

「错超过 5 次才重来」和「正确率 > 60%」在答对 5、6 个时冲突，已确认按严格那条：

| 答对 | 结果 |
|---|---|
| 7–10 | 解锁 15 分钟 |
| 0–6 | 不解锁，提示「错得有点多，再来一组」，重新取 10 词 |

对应常量 `QuizRules.PASS_CORRECT = 7`，需要放宽时只改这一处。

### 7.2 错题：严格 7 天，当天不重练

所有进过一组的词，无论对错，`last_seen_at` 立刻更新，7 天内不再进入候选池。
本轮答错的词，下一组也不会出现。

知情代价：当天错当天复习其实更符合记忆规律。这个取舍是明确选择的——规则简单、可预期，
孩子也能感受到「这词我做过就不会马上再考我」。`wrong_retry_hours` 开关保留在代码里，默认 0 关闭。

### 7.3 答错当场给答案

默写答错的瞬间：红字提示 + 正确拼写停 1.5 秒，然后进下一题。结果页再统一回看错题。
理由是这条路径的定位是**学习工具**，不是考试——当场纠错比事后回看有效。
